题目数据结构说明 (questions.json)

题目编写者参考此格式 · 系统动态读取 · 不写死数量

整体结构
{
  "round1_required": [ ... ],      // 第一环节·必答题（5道）
  "round1_buzzer": [ ... ],        // 第一环节·抢答题（20道）
  "round2_pk": [ [ ... ], [ ... ], [ ... ], [ ... ] ],  // 第二环节·4组PK（每组5道）
  "round3_semifinal": [ [ ... ], [ ... ] ],  // 第三环节·2组半决赛（每组5道）
  "round4_final": [ ... ],         // 第四环节·决赛（9道：3易3中3难）
  "tiebreaker": [ [ ... ], [ ... ], ... ]  // 加赛备用题（N组，每组5道，数量不限）
}
单题结构
{
  "id": 1,
  "question": "我国国防的核心是？",
  "options": {
    "A": "人民战争",
    "B": "信息化战争",
    "C": "总体战",
    "D": "混合战争"
  },
  "answer": "A",
  "points": 10,
  "difficulty": "easy"  // 仅决赛题需要：easy/medium/hard
}
字段类型必填说明
idnumber是题号，组内从1开始
questionstring是题干文字
optionsobject是4个选项 A/B/C/D
answerstring是正确答案，值为 "A"/"B"/"C"/"D"
pointsnumber是分值：5/10/15（决赛不同，其余均为10）
difficultystring仅决赛"easy"=5分 / "medium"=10分 / "hard"=15分
各环节详情

第一环节·必答题（5道）

"round1_required": [
  { "id": 1, "question": "...", "options": {"A":"...","B":"...","C":"...","D":"..."}, "answer": "A", "points": 10 },
  // ... 共5道
]

第一环节·抢答题（20道）

"round1_buzzer": [
  { "id": 1, "question": "...", "options": {...}, "answer": "B", "points": 10 },
  // ... 共20道
]

第二环节·4组PK（每组5道）

"round2_pk": [
  [ // 第1组PK（1v8对阵）
    { "id": 1, "question": "...", "options": {...}, "answer": "A", "points": 10 },
    // ... 共5道
  ],
  [ // 第2组PK（2v7对阵） ... ],
  [ // 第3组PK（3v6对阵） ... ],
  [ // 第4组PK（4v5对阵） ... ]
]

第三环节·2组半决赛（每组5道）

"round3_semifinal": [
  [ // 半决赛A组
    { "id": 1, "question": "...", "options": {...}, "answer": "C", "points": 10 },
    // ... 共5道
  ],
  [ // 半决赛B组 ... ]
]

第四环节·决赛（9道）

"round4_final": [
  { "id": 1, "question": "...", "options": {...}, "answer": "A", "points": 5,  "difficulty": "easy" },
  { "id": 2, "question": "...", "options": {...}, "answer": "B", "points": 5,  "difficulty": "easy" },
  { "id": 3, "question": "...", "options": {...}, "answer": "D", "points": 5,  "difficulty": "easy" },
  { "id": 4, "question": "...", "options": {...}, "answer": "A", "points": 10, "difficulty": "medium" },
  // ... 3道medium(10分) + 3道hard(15分)，共9道
]
第9题（id=9）为平局抢答专用题，difficulty为"hard"。

加赛备用题（N组，数量不限）

"tiebreaker": [
  [ // 第1组
    { "id": 1, "question": "...", "options": {...}, "answer": "B", "points": 10 },
    // ... 共5道
  ],
  [ // 第2组 ... ],
  [ // 第3组 ... ],
  // ... 组数不限，多多益善
]
系统会自动读取tiebreaker数组的长度，动态显示"第X组 / 共N组"。加赛时从未使用的最低编号组开始依次使用。
注意事项
1. 所有题目的 points 字段：必答题/抢答题/PK/半决赛 = 10，决赛简单 = 5，决赛中等 = 10，决赛难题 = 15
2. 决赛题必须有 difficulty 字段，其他环节题目可省略
3. options 固定4个选项 A/B/C/D，不需要的可以留空字符串
4. answer 必须是 "A"/"B"/"C"/"D" 之一
5. 题目组数和每组题数均由JSON决定，系统不写死
6. 文件名固定为 questions.json，放在项目根目录
7. 替换题目只需替换此文件，无需修改代码
