同步机制：管理端切换题目/环节时，展示端自动同步跟随。答案显示、得分变化均由管理端控制，实时推送到展示端。

每轮计分方式
轮次计分方式说明
第一环节总分累加必答+抢答所有得分累加，按总分排名，前8名晋级
第二环节(8进4)从0分开始每组PK独立计分，不带入第一环节分数，高分者晋级
第三环节(4进2)从0分开始半决赛独立计分，高分者晋级决赛
第四环节(决赛)从0分开始决赛独立计分，交替选题，总分高者夺冠
加赛分数不计入总分仅用于决定排名/胜负，5题抢答
完整比赛流程
1 第一环节：同心协力（14进8） 必答5道 + 抢答20道
必答题5道→ 全部队伍统一作答→ 管理端逐队判分→ 抢答题20道→ 3-2-1倒计时抢答→ 排名展示→ 平分?加赛→ 前8名晋级
2 第二环节：突围时刻（8进4） 4组PK · 每组5题
展示对阵图→ 1v8 PK(5题)→ 2v7 PK(5题)→ 3v6 PK(5题)→ 4v5 PK(5题)→ 4胜者晋级半决赛

每组PK从0分开始，抢答5题(+10/-10)，平局则加赛

3 第三环节：半决赛（4进2） 2组PK · 每组5题
半决赛A组PK(5题)→ 半决赛B组PK(5题)→ 两人分数相同?→ 加赛定选题顺序→ 2胜者晋级决赛

半决赛分数不带入决赛，但决定决赛选题顺序。两人分数相同时先加赛排名。

4 第四环节：决赛（2进1） 9题 · 交替选题
展示9题总览→ A选题→B选题→A→B→A→B→A→B(共8题)→ 平分?→ 第9题抢答定胜负→ 冠军诞生

简单3道(5分)/中等3道(10分)/难题3道(15分)，每队答4题交替选题

! 加赛环节：锦上添花（任意平局时触发） 4组备用题 · 每组5题
触发场景参与者题目来源计分
第一环节排名平分所有平分队伍第1组(首次)→第2组→...不计入总分，仅定排名
第二环节PK平局平局的两支队伍未使用的下一组不计入总分，仅定胜负
半决赛平局平局的两支队伍未使用的下一组不计入总分，仅定胜负/选题顺序
决赛平局决赛两支队伍第9题抢答/未使用的下一组不计入总分，一局定胜负
题目不重复原则：4组加赛题按顺序使用（第1次加赛用第1组，第2次用第2组），已使用的题目不再出现。

管理端页面规划

管理端 运行于电脑主屏，主持人/操作员使用。所有操作实时同步到展示端。支持完整撤销/回退 + 手动改分 + 答题历史 + 数据导出。

1 总控台 / 仪表盘 全程可用
  • 当前环节大字显示 + 当前题号/总题数进度指示
  • 全局环节进度面包屑导航：第一环节 → 第二环节 → 第三环节 → 第四环节 → 颁奖（当前环节高亮，可点击跳转）
  • 快速操作按钮区：
    • [开始竞赛] 按钮 — 开场启动，展示端显示封面
    • [上一题] [下一题] [显示/隐藏答案] [开始抢答] 按钮
    • [进入下一环节] 按钮 — 当前环节全部完成后进入下一环节
  • 连接状态指示：WebSocket（绿/红点）+ DLL TCP（绿/红点）+ [手动重连DLL]按钮
  • 音效总开关 + 分类开关：[倒计时] [抢答成功] [犯规警告] [答对] [答错]
  • 答题历史摘要（最近5条操作记录）
  • [撤销上一步]按钮
  • [导出数据]按钮 — 快捷入口（同设置页导出功能）
2 队伍管理 全程可用
  • 14支连队列表，按实时分数排序，显示排名
  • 每队显示：排名徽章、连队名、当前分数、状态（参赛/淘汰）
  • 每队操作按钮组（点击展开）：
    • [+5] [+10] [+15] [-5] [-10] [-15] 加减分按钮
    • [自定义分值] 输入框 + [确认]按钮
    • [手动改分] 输入框 + [覆盖]按钮（直接覆盖分数）
    • [激活] / [淘汰] 切换按钮
    • [判负] 按钮（作弊判负，二次确认弹窗）
  • 批量操作按钮：[重置全部分数] [全部激活] [全部淘汰]
  • 分数变动后展示端同步动画
  • [返回总控台] 按钮
3 必答题控制 第一环节 · 必答题阶段
  • 题目列表导航（1-5题），当前题高亮
  • 当前题目预览（题干+选项+正确答案）
  • [显示答案] / [隐藏答案] 按钮 — 控制展示端答案显示/隐藏
  • [上一题] [下一题] 按钮
  • 逐队判分面板：14支连队，每队三个按钮：
    • [答对 +10分] 按钮
    • [答错 0分] 按钮（不扣分）
    • [违规 -10分] 按钮
    • [判负] 按钮（作弊，二次确认）
  • 已判分队伍显示标记（✓答对 / ✗答错 / ⚠违规 / ✗判负）
  • 批量操作按钮：[全部答对] [清除本题判分]
  • [撤销本题所有判分] 按钮
  • 判分后展示端实时更新分数
  • 5题全部完成后 → [进入抢答阶段] 按钮亮起
  • [返回总控台] 按钮
4 抢答控制 抢答 第一/二/三环节
  • 题目列表导航，当前题高亮
  • 当前题目预览（题干+选项+正确答案）
  • [上一题] [下一题] [显示/隐藏答案] 按钮
  • 抢答状态机控制台：
    • 状态显示：待开始 → 倒计时中(3-2-1) → 抢答开放 → 已抢答 → 已判分
    • [开始抢答] 按钮 — 触发展示端3-2-1倒计时
    • 抢答者显示 — DLL返回key_id后自动映射显示连队名
    • DLL未就绪时 — [手动选择抢答队伍] 下拉列表 + [确认]按钮
    • [答对] 按钮 — 加分 + 展示端绿色标识
    • [答错] 按钮 — 扣分 + 展示端蓝色标识
    • [手动犯规] 按钮 — DLL漏检时手动标记某队犯规
    • [判负] 按钮 — 作弊判负，二次确认
    • [跳过此题] 按钮 — 无人抢答时手动跳过
    • [取消抢答] 按钮 — 回到待开始状态
    • 超时设置 — 自动跳过时间（默认10秒）
  • 3秒答题计时器 — 抢到后自动启动，超时标记答错（仅显示，无声音）
  • 答题历史记录（本题哪队抢答、结果如何）
  • [撤销] 按钮 — 回退本题操作
  • 20题全部完成后 → [进入排名确认] 按钮亮起
  • [返回总控台] 按钮
5 排名确认 第一环节结束后

  • 前8名标记"晋级"，后6名标记"优秀奖"
  • 平局自动检测：
    • 平分队伍红色高亮

  • 每组PK：[进入PK控制] 按钮
  • 每组PK结果记录（胜者/负者/分数）

  • 双方PK分数（从0开始，实时显示）
  • 5题抢答控制：
    • [上一题] [下一题] [显示/隐藏答案] 按钮
    • [开始抢答] 按钮 — 3-2-1倒计时
    • [手动选择抢答队伍] 下拉列表（DLL降级时）
    • [答对] 按钮 — +10分
    • [答错] 按钮 — -10分
    • [手动犯规] 按钮 — 手动标记犯规
    • [跳过此题] 按钮
    • [取消抢答] 按钮
    • [判负] 按钮 — 作弊判负，对手自动获胜（二次确认）
  • 每题结果记录（哪队抢答、答对/答错/犯规）
  • [显示答案] 按钮
  • [撤销] 按钮
  • 5题结束后：

    • 分数相同 → 提示"平局" → [开始加赛] 按钮

  • [返回对阵管理] 按钮

  • [确认选题顺序] 按钮 — 半决赛排名决定或加赛后确认

  • 当前选题队伍高亮
  • 选题操作：点击某题 → [确认选题] 按钮 → 展示端显示该题
  • [答对] 按钮 — +对应分值（5/10/15）
  • [答错] 按钮 — -对应分值（5/10/15）
  • [手动犯规] 按钮 — 手动标记犯规
  • [判负] 按钮 — 作弊判负，对手夺冠（二次确认）

  • 冠军确认后 → [进入颁奖] 按钮亮起
  • [返回总控台] 按钮
9 加赛控制 任意平局时
  • 第一步 — 平局检测（自动）：
    • 系统自动检测当前环节是否有平分
    • 若无平分 → 自动跳过加赛，进入下一环节
    • 若有平分 → 显示平局列表：
      • 第一环节示例："检测到2处平分：第3-4名(三连=四连=30分) / 第7-8名(七连=八连=20分)"
      • 第二环节示例："PK1平局：一连 20 = 八连 20"
      • 半决赛示例："半决赛A 25 = 半决赛B 25，需决定选题顺序"
      • 决赛示例："决赛 35 = 35，进入第9题抢答"
    • 每处平分独立处理，第一环节从高名次开始依次加赛
  • 第二步 — 题组自动分配：
    • 系统自动选择未使用的最低编号题组（第1组→第2组→第3组→第4组）
    • 已使用题组标记为灰色划线，不可重复使用
    • 显示："本次加赛使用第X组（5题），剩余Y组可用"
    • 若是本环节第2处平分 → 自动用下一组
  • 第三步 — 加赛执行（5题抢答）：
    • 题目导航：1-5题，当前题高亮，已答题显示结果标记
    • 当前题目预览：题干+选项+正确答案（管理端可见答案）
    • 抢答控制台（仅限参与加赛的队伍）：
      • [上一题] [下一题] [显示/隐藏答案] 按钮
      • [开始抢答] 按钮 → 3-2-1倒计时 → DLL开放抢答
      • DLL未就绪 → [手动选择抢答队伍] 下拉列表
      • [答对] 按钮
      • [答错] 按钮
      • [手动犯规] 按钮 — 手动标记犯规
      • [判负] 按钮 — 作弊判负（二次确认）
      • [跳过此题] 按钮 — 无人抢答时跳过
      • [取消抢答] 按钮
      • [撤销] 按钮
      • 3秒答题计时（有显示无声音），超时算答错
    • 加赛积分表（独立于总分，从0开始）：实时显示各队加赛分数
  • 第四步 — 加赛结果判定：
    • 5题结束后，系统自动按加赛分数排序
    • 分数不同 → 自动确定排名/胜负：
      • 第一环节 → 更新对应名次排名（分数不计入总分）
      • 第二环节PK → 胜者晋级，负者淘汰（PK分数不计入总分）
      • 半决赛 → 胜者获得决赛优先选题权
    • 仍有平分 → 系统提示"平分未决"，自动分配下一组题，回到第三步
    • 4组用完仍有平分 → 提示"备用题已用完"，管理端手动判定胜负
  • 第五步 — 多处平分处理（第一环节）：
    • 第1处平分解决后，显示"第1处 ✓"，自动跳到第2处
    • 分配下一组题，重复第二~四步
    • 所有平分解决 → 显示完整排名 → "确认排名"按钮 → 进入第二环节
    • 每处平分独立计分，加赛分数互不影响
  • 决赛第9题特殊流程：
    • 决赛8题后检测到平分 → 进入第9题抢答模式
    • 展示端显示"平局！第9题 — 抢答定胜负"（醒目红色）
    • 3-2-1倒计时 → 抢答 → 判分：
      • 答对 → 该队夺冠，比赛结束
      • 答错 → 对方夺冠，比赛结束
      • 犯规 → 该队取消资格，对方夺冠
      • 无人抢答 → 管理端手动判定或使用备用题组
    • 一局定胜负，不进行5题循环
  • 加赛历史记录：
    • 记录每次加赛：触发原因、参与队伍、使用题组、各题结果、最终排名/胜负
    • 已使用题组列表显示（供参考）
    • 支持撤销最近一次加赛结果（回退到加赛前状态）
  • [返回原环节] 按钮 — 加赛结束后返回触发加赛的环节页面

  • [保存全部设置] 按钮 — 保存以上所有配置
  • [返回总控台] 按钮

两种倒计时的区别：
· 抢答开始倒计时（3-2-1）：管理端点"开始抢答"后触发，有声音（3声"滴"），用于告诉选手可以开始抢答了
· 3秒答题计时：选手抢到后触发，无声音（仅画面显示），用于限制答题时间，超时算答错

边界情况与处理方案
! DLL相关
情况处理方案
DLL未就绪/连接失败管理端可手动选择哪个队抢答（下拉列表），系统功能不受影响
DLL TCP断线自动重连（间隔3秒），重连期间抢答功能切换为手动模式
DLL返回未知key_id提示"未知抢答器编号，请在设置中配置映射"，忽略该事件
多个抢答事件同时到达取timestamp最早的一个作为抢答者，其余忽略
非参赛队伍抢答器误触系统自动过滤：如1v8 PK时5连误触 → 管理端提示"5连非本场参赛队伍，已忽略"，展示端不显示
! 比赛流程相关
情况处理方案
第一环节多处平分从高名次开始依次独立加赛，每处平分单独处理
加赛5题后仍然平分自动使用下一组备用题继续加赛，直到决出胜负
4组备用题全部用完提示"备用题已用完，请手动处理"，由管理端手动判定
抢答开放期间无人抢答10秒自动超时跳过，管理端也可手动"跳过此题"
抢答后3秒内未作答自动标记为答错，按规则扣分
抢答犯规后该队取消本题资格，其他队伍继续抢答（回到OPEN状态）
抢到但答错本题直接结束，进入下一题（不允许其他队继续抢）
决赛8题后平分使用剩余第9题以抢答形式一局定胜负
! 系统相关
情况处理方案
浏览器音频限制展示端首次加载需用户点击一次解锁音频，页面显示"点击开始"提示
展示端全屏页面提供"全屏"按钮，点击后自动全屏（F11效果）。也可手动拖拽到副屏后全屏
倒计时时间源3-2-1倒计时和3秒答题计时均由Node.js服务端控制时间戳，避免管理端与展示端不同步
浏览器误关闭/刷新状态实时持久化到state.json，重新打开自动恢复到断点
WebSocket断线自动重连（间隔2秒），重连后请求全量状态同步
多个管理端同时操作最后操作覆盖，不做锁定。建议只开一个管理端
