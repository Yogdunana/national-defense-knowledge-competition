# 国防知识竞赛计分系统

## 快速部署

### 1. 安装依赖
```bash
pip install flask flask-socketio simple-websocket
```

### 2. 启动服务
```bash
# Linux/Mac
bash start.sh

# Windows
双击 start.bat
```

### 3. 访问页面
- **大屏展示**: 浏览器打开 `http://服务器IP:5000`
- **手机控制**: 手机浏览器打开 `http://服务器IP:5000/mobile`

> 确保手机和展示电脑在同一内网。

## 使用说明

### 大屏页面
- 左右方向键翻页，空格下一页
- A键显示/隐藏答案
- F键全屏
- 点击底部导航跳转题目
- 每环节结束有排名页

### 手机端
- 点击连队选中
- 底部绿色按钮加分(+5/+10/+15)
- 底部红色按钮减分(-5/-10/-15)
- 实时显示分数和排名
- "参与/淘汰"按钮切换连队状态

## 竞赛结构
1. 第一环节：同心协力（必答5题+抢答20题）
2. 第二环节：突围淘汰赛（4组PK）
3. 第三环节：半决赛（5题）
4. 第四环节：决赛（9题）
5. 第五环节：锦上添花（平局加赛）
