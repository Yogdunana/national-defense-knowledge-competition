# 宝塔面板部署指南

## 方案一：宝塔 Python 项目管理器（推荐）

### 1. 安装 Python 项目管理器
宝塔面板「软件商店」→ 搜索 `Python项目管理器` → 安装

### 2. 上传项目
宝塔「文件」→ 上传 `contest` 文件夹到 `/www/wwwroot/contest`

### 3. 创建 Python 项目
宝塔「Python项目」→ 添加项目，按以下填写：

| 配置项 | 填写内容 |
|--------|---------|
| 项目名称 | `contest` |
| 路径 | `/www/wwwroot/contest` |
| Python版本 | `3.8` 或更高 |
| 框架 | `Flask` |
| 启动方式 | `Gunicorn` |
| 启动文件/模块 | `wsgi:application` |
| 端口 | `5000` |
| 启动参数 | `--worker-class eventlet --workers 1 --bind 0.0.0.0:5000` |

### 4. 安装依赖
项目创建后，进入项目终端执行：
```bash
cd /www/wwwroot/contest
pip3 install -r requirements.txt
```

> 如果 pip 安装慢，可换源：
> ```bash
> pip3 install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
> ```

### 5. 启动项目
点击项目列表中的「启动」按钮

### 6. 放行端口
宝塔「安全」→ 放行 `5000` 端口（TCP）

### 7. 访问
- 大屏：`http://服务器IP:5000`
- 手机端：`http://服务器IP:5000/mobile`

---

## 方案二：终端直接运行（最简单稳定）

如果 Python 项目管理器仍有问题，用这个方法最可靠：

### 1. 上传项目并安装依赖
```bash
cd /www/wwwroot/contest
pip3 install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
```

### 2. 测试能否正常启动
```bash
python3 app.py
```
看到打印出地址说明成功，`Ctrl+C` 停止。

### 3. 后台常驻运行
```bash
cd /www/wwwroot/contest
nohup python3 app.py > contest.log 2>&1 &
```

### 4. 查看日志
```bash
cat /www/wwwroot/contest/contest.log
```

### 5. 停止服务
```bash
kill $(pgrep -f "python3 app.py")
```

### 6. 设置开机自启
宝塔「计划任务」→ 添加任务：
- 类型：`Shell脚本`
- 执行周期：`开机启动`
- 脚本内容：`cd /www/wwwroot/contest && nohup python3 app.py > contest.log 2>&1 &`

## 方案三：Docker 部署

### 1. 上传项目
上传 `contest` 文件夹到 `/www/wwwroot/contest`

### 2. 构建并运行
```bash
cd /www/wwwroot/contest
docker-compose up -d --build
```

### 3. 放行端口
宝塔「安全」→ 放行 `5000` 端口

---

## 方案四：Nginx 反向代理（用80端口访问）

在方案二/三基础上，用宝塔 Nginx 代理到 5000 端口：

### 1. 新建站点
宝塔「网站」→ 添加站点 → 域名填服务器IP

### 2. 配置反向代理
站点设置 → 反向代理 → 添加：
- 代理名称：`contest`
- 目标URL：`http://127.0.0.1:5000`
- 发送域名：`$host`

### 3. 修改 Nginx 配置（关键！支持 WebSocket）
站点设置 → 配置文件，`location /` 改为：
```nginx
location / {
    proxy_pass http://127.0.0.1:5000;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}
```

### 4. 访问（无需端口号）
- 大屏：`http://服务器IP`
- 手机端：`http://服务器IP/mobile`

## 常见问题

**Q: 宝塔 Python 项目启动失败？**
1. 确认启动参数填写了 `--worker-class eventlet`
2. 确认依赖已安装：`pip3 install -r requirements.txt`
3. 如果仍失败，改用方案二（终端直接运行）

**Q: 访问不了？**
检查防火墙是否放行 5000 端口，宝塔安全 + 服务器安全组都要放行

**Q: 手机端连不上？**
确保手机和服务器在同一内网，用服务器内网IP访问

**Q: WebSocket 不工作 / 分数不刷新？**
1. 如果用了 Nginx 代理，确认配置了 `Upgrade` 和 `Connection` 那几行
2. 确认 `eventlet` 已安装

**Q: 重启后服务没了？**
用方案二设置开机自启计划任务，或用 Docker 自动重启
